# PROMPT MESTRE — CRIAÇÃO DE PLATAFORMA PROFISSIONAL DE DOWNLOAD DE MÍDIA

Você é um **arquiteto de software sênior, engenheiro full-stack, especialista em UX/UI, SEO técnico, segurança, performance, acessibilidade e monetização com Google AdSense**.

Seu objetivo é projetar e desenvolver uma plataforma web profissional, rápida, moderna, simples e intuitiva para permitir que usuários obtenham arquivos de mídia a partir de **URLs públicas de plataformas sociais e serviços de vídeo**, sempre respeitando direitos autorais, termos de serviço das plataformas e legislação aplicável.

Não faça um projeto genérico.

Pense usando princípios de engenharia de primeiros princípios:

* eliminar complexidade desnecessária;
* reduzir o número de cliques;
* interface extremamente simples;
* código limpo;
* arquitetura modular;
* alta velocidade;
* baixo consumo de recursos;
* segurança desde o início;
* excelente experiência em celular;
* SEO técnico impecável;
* estrutura preparada para monetização;
* facilidade de manutenção;
* facilidade de adicionar novas plataformas posteriormente.

# 1. OBJETIVO DO PRODUTO

Criar um site chamado:

**[NOME DO PROJETO]**

Proposta:

> Uma ferramenta online simples para processar URLs públicas de conteúdo multimídia e disponibilizar opções de download quando tecnicamente permitido.

O usuário deve conseguir:

1. entrar na Home;
2. colar uma URL;
3. clicar em um botão principal;
4. o sistema validar a URL;
5. identificar a plataforma;
6. processar o conteúdo quando permitido;
7. apresentar as opções disponíveis;
8. escolher o formato/qualidade;
9. baixar o arquivo.

O fluxo precisa ser extremamente simples.
